# RAIL INSIGHT · 철도 운영 분석

Streamlit으로 설비 센서·AI 판정·온도 예측과 역별 승하차·민원을 확인하는 교육용 대시보드입니다.

## 실행

```sh
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

`app.py`, `dashboard_data.py`, 두 CSV, `requirements.txt`, `.streamlit/config.toml`을 저장소 구조 그대로 사용합니다. CSV 경로는 앱 파일 기준으로 계산하므로 작업 디렉터리나 Colab Drive 경로에 의존하지 않습니다. CSV가 없으면 사이드바의 ‘데이터 파일 변경’을 펼쳐 업로드할 수 있습니다.

## 화면 구성

- **설비 분석**: 종합 현황, 온도·진동·전류·부하율 상세, AI/규칙 후보 비교, 예측 MAE·RMSE·편향, 검토 메모와 CSV/TXT/ZIP 다운로드.
- **역 이용 현황**: 승하차·민원 추이, 평일/주말 일평균, 역별 이용량과 승하차 1만 건당 민원, 원자료·요약 다운로드.
- 설비/역을 여러 개 선택하고 시작일·종료일을 지정한 뒤 **조회 적용**을 누릅니다. 날짜 양끝을 포함합니다. 두 메뉴는 독립적인 조회 조건을 사용합니다.
- 업로드한 파일별로 조회 조건을 구분합니다. 메모는 파일·설비·기간별로 현재 접속 세션에 저장되며, 영구 보관하려면 보고서를 내려받습니다.
- 그래프 툴바에서 확대/초기화/PNG 저장, 표에서 정렬/검색을 사용할 수 있습니다.

## 지표 해석

- AI 확인후보는 고장 확정이 아니며, 후보 행 수는 고장 발생 횟수가 아닙니다.
- 확인후보 비율은 현재 조회 전체 행을 분모로 사용합니다. 입력부족과 판정 누락은 별도 표시합니다.
- MAE·RMSE·평균 편향은 실제값과 예측값이 모두 유효한 행만 사용합니다. 편향은 예측−실제입니다. 목표시각이 없으면 시간 그래프에서는 제외하고 이를 안내합니다.
- 예측 탭은 CSV에 저장된 값을 비교합니다. 신규 모델 학습이나 실시간 추론을 수행하지 않습니다. 조회 기간은 측정시각 기준이므로 예측 목표시각이 종료일을 넘어갈 수 있습니다.
- 승하차 건수는 고유 이용자 수가 아닙니다. 1만 건당 민원은 승하차 합계와 민원 모두 유효한 행을 묶어 계산합니다. 분모가 0이면 비율을 표시하지 않습니다.
- 평일/주말 비교는 현재 선택 조건에서 자료가 있는 날짜의 일평균입니다.
- 잘못된 숫자·무한대는 결측 처리합니다. 역 이용 건수의 음수·소수는 결측 처리합니다. 날짜·식별자가 없는 행은 제외하고, 동일 식별자/시각 중복은 삭제 없이 건수를 표시합니다.
- 기본 제공 자료: 설비 1개, 시간별 168행; 역 4개, 일별 56행. 다른 설비를 포함한 CSV를 업로드하면 설비 비교가 확장됩니다.

## Streamlit Community Cloud 반영

Streamlit Cloud 배포 설정에서 이 저장소의 `main` 브랜치와 `app.py`를 선택하세요. 별도 브랜치의 변경은 PR을 `main`에 병합한 뒤 운영 앱에 반영됩니다. `requirements.txt`가 바뀌면 패키지 설치를 포함한 재배포가 진행될 수 있습니다. 실제 앱의 연결 브랜치 설정은 Cloud 관리 화면에서 확인하세요.
